Good body text is mostly invisible. Readers notice it only when it gets in the way.

## Line length

Aim for 60 to 75 characters per line. Longer lines make it hard to find the start of the next one.

## Size and spacing

1. Start at 16 to 18 pixels for body text.
2. Set the line height around 1.5.
3. Give headings more space above than below, so they belong to the text that follows.

> Typography exists to honor content.
