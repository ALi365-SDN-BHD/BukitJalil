# BukitJalil V1 Backlog

## 1. 文档目标

本 backlog 用于把 `BukitJalil V1 Implementation Plan` 继续拆成可执行任务。

它的用途是：

- 作为开发排期基础；
- 作为阶段推进的任务清单；
- 作为后续 issue、milestone、task board 的来源；
- 作为“是否可以进入下一阶段”的检查表。

## 2. 使用方式

### 2.1 优先级定义

- `P0`：不完成就无法形成 V1 主闭环；
- `P1`：强烈建议在 V1 完成；
- `P2`：可延后到 V1 后半段或 V1.5；
- `P3`：仅记录，不进入当前开发主线。

### 2.2 状态定义

建议后续在任务系统中使用以下状态：

- `Todo`
- `In Progress`
- `Blocked`
- `Review`
- `Done`

### 2.3 验收方式

每个任务至少具备一种验收方式：

- 可运行验证；
- 手动操作验证；
- 自动测试验证；
- UI 截图或录屏验证。
