# BukitJalil v0.1.0-beta.11

**每一次笔记，都值得被看见；让 AI 帮你实现它。**

这是测试版，适合自己试用，不建议用在正式网站上。和 beta.10 相比的主要变化如下。

## 升级前请注意

这一版改了数据的保存方式。旧版的数据库没有加密，新版打不开，第一次启动时只能选择重置。重置会清空应用里的网站列表、对话、发布账号、Notion 数据源和模型密钥，你电脑上的网站和主题文件夹不会被删除。重置后，请把网站文件夹重新导入，再重新填写 token 和密钥。

## PIN 锁定

- 桌面版第一次启动时要设置一个 4–8 位数字的 PIN，以后每次打开都要输入。
- 应用的数据都存在一个加密的数据库里，用 PIN 解锁，包括发布账号、Notion 数据源、模型密钥和对话记录。不再使用系统钥匙串，所以 macOS 不会再弹出钥匙串提示。
- 可以随时手动锁定。也可以在设置里打开空闲自动锁定，可选 1、5、10、15、30 分钟，默认关闭。锁定期间，正在进行的 AI 对话、构建和发布会继续做完。
- 连续输错 5 次 PIN，要等 5 分钟才能再试。
- 忘记 PIN 时，可以在锁屏上重置应用，效果和上面升级时的重置一样。

## 内容管理（Notion）

左上角新增第三个模式"内容管理"，直接管理 Notion 数据源里的内容，不针对某个网站。

- 左栏列出所有数据源和它们能访问的数据库，中栏是条目列表和正文，右栏是属性。
- 可以新建条目，修改标题、属性和正文。保存直接写进 Notion，不经过审核，也不留版本；网站下次正式构建时会用上新内容。
- 正文用 Markdown 编辑，只有正文里所有块都在支持范围内时才能编辑，否则只能查看，并提供"在 Notion 中打开"。图片只支持外链。
- 保存前会检查 Notion 里的条目有没有被别人改过，有的话提示冲突，重新载入后再改。

## 其他

- 内置的 Bukit 升级到 2.2.7。这一版 Bukit 新增了可选的小程序数据输出，BukitJalil 暂时没有对应的设置界面；不用这项功能的网站，构建结果不变。

## 已知问题

- macOS 安装包没有用开发者证书签名：第一次打开要右键点应用、选"打开"。
- 拿到 `app.db` 文件的人可以离线反复试 PIN，错误次数限制管不住。PIN 主要防止你离开时别人打开应用。
- 内容管理还没在真实的 Notion 上把所有情况试一遍，包括多个数据源的数据库和在正文中间插入的块。
- 应用内更新下载的安装包和校验文件来自同一个 GitHub 发布，没有独立签名，只适合测试使用。对外发布前会先决定签名方案。
- Intel Mac 和 Linux ARM 的安装包只经过发布流程里的冒烟测试，没有在真机上完整试用。
- Windows 版只是预览，还不支持。
