# BukitJalil v0.1.0-beta.10

**每一次笔记，都值得被看见；让 AI 帮你实现它。**

这是测试版，适合自己试用，不建议用在正式网站上。和 beta.9 相比的主要变化如下。

## 主题开发

左栏顶部可以在"网站构建"和"主题开发"之间切换。主题开发做的是 Bukit 主题，每个主题自带一份样例内容用来预览。

- **按描述新建主题**：写下想要的风格，可以附参考图，AI 从 Bukit 的 starter 主题开始改。AI 会先做配色、字体、页头页脚和首页，请你在预览里确认风格，确认后再做其他页面类型。
- **主题面板**：预览可以切换页面类型和屏幕宽度；还能查看主题覆盖了哪些页面、用了哪些颜色，以及样例内容和参考图。
- **导入主题**：从文件夹或 zip 导入已有的主题。选中的如果是网站文件夹，会转到导入网站。
- **克隆网站（仅桌面版）**：输入一个网址，应用在隔离的窗口里打开并抓取页面，再由 AI 转成 Bukit 主题。只抓取你有权使用的网站。
- **应用到网站、导出**：做好的主题可以作为一次改动应用到某个网站，审核后生效；网站自己上传的素材会保留。也可以导出成 zip。

## 其他

- 对话框里还没发出的文字和图片会一直保留，切到别的对话或模式再回来也还在，发出后才清空。
- 右侧面板的标签页可以用 Alt+数字切换，鼠标悬停时会显示对应的快捷键。

## 已知问题

- macOS 安装包没有用开发者证书签名：第一次打开要右键点应用、选"打开"；每装一个新版本，macOS 会再问一次钥匙串，点"始终允许"即可。
- 应用内更新下载的安装包和校验文件来自同一个 GitHub 发布，没有独立签名，只适合测试使用。对外发布前会先决定签名方案。
- Intel Mac 和 Linux ARM 的安装包只经过发布流程里的冒烟测试，没有在真机上完整试用。
- Windows 版只是预览，还不支持。
