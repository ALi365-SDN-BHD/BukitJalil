# BukitJalil v0.1.0-beta.4

**每一次笔记，都值得被看见；让 AI 帮你实现它。**

这是测试版，适合自己试用，不建议用在正式网站上。和 beta.3 相比的主要变化如下。

## 安全

- **AI 改动的预览不再露出 Notion 隐藏字段和草稿**：检查、构建和预览 AI 改动时，每个 Notion 源的字段、过滤、排序、条数和是否读正文都按正式版本，AI 在 `site.yaml` 里改了这些也不生效。预览上会提示"Notion 字段和过滤按正式版本，这些改动应用并正式构建后才生效"。修好了 beta.3 的已知问题。
- 正式构建时记下 Notion 源对应的数据库，AI 交换两个源的名字也不能把一个源的设置套到另一个数据库上。

## Bukit

- **内置 Bukit 升到 2.2.3**：支持离线构建固定 Notion 设置；发布到 GitHub Pages 时 token 经凭证中转交给 git，不再进 git 的环境变量；macOS 和 Windows 版本可以重复构建出相同的文件。

## 升级说明

- 已有 Notion 网站的离线快照是 beta.3 记录的，没有正式版本的设置。升级后第一次检查或预览 AI 改动前，会提示先在网站页面正式构建一次。

## 已知问题

- macOS 安装包没有用开发者证书签名：第一次打开要右键点应用、选"打开"；每装一个新版本，macOS 会再问一次钥匙串，点"始终允许"即可。
- Windows 版只是预览，还不支持。
