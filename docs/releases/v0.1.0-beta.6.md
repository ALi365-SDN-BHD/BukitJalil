# BukitJalil v0.1.0-beta.6

**每一次笔记，都值得被看见；让 AI 帮你实现它。**

这是测试版，适合自己试用，不建议用在正式网站上。和 beta.5 相比的主要变化如下。

## Bukit

- **内置 Bukit 升到 2.2.6**，AI 用的 Bukit 技能同步到 2.2.6（内容与 2.2.5 相同）。
- **预览里的搜索可以用了**：Bukit 2.2.6 提供脚本形式的搜索索引。预览禁止页面请求文件，搜索页会改用同源脚本读取索引。在 Chromium、Firefox、WebKit 里都验证过。
- **多文档的 `site.yaml` 直接拒绝**：Bukit 2.2.6 不再静默忽略 `...` 或 `---` 之后的内容，构建前和 Bukit 都会拦下，并说明把设置移到这一行之前。
- **新建网站**生成的搜索页随 Bukit 2.2.6 更新。

## 其他

- 修复 biome 检查没有通过的问题，桌面测试的端口不再占用预览端口池。

## 已知问题

- macOS 安装包没有用开发者证书签名：第一次打开要右键点应用、选"打开"；每装一个新版本，macOS 会再问一次钥匙串，点"始终允许"即可。
- 应用内更新下载的安装包和校验文件来自同一个 GitHub 发布，没有独立签名，只适合测试使用。对外发布前会先决定签名方案。
- Intel Mac 和 Linux ARM 的安装包只经过发布流程里的冒烟测试，没有在真机上完整试用。
- Windows 版只是预览，还不支持。
