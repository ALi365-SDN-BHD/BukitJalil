# BukitJalil v0.1.0-beta.7

**每一次笔记，都值得被看见；让 AI 帮你实现它。**

这是测试版，适合自己试用，不建议用在正式网站上。和 beta.6 相比的主要变化如下。

## 素材上传

- **上传入口放在预览面板**：预览面板顶部的"刷新"按钮左侧现在是"上传素材"，网站主页不再单独放上传按钮。点它会跳到改动面板并直接打开文件选择框，上传队列、重名提示和新文件都留在改动面板这一处。
- **修好上传第一个文件时队列和对话框消失**：改动面板以前会在这个时候重建上传组件，把刚加入的队列和"替换还是跳过"的提示一起丢掉；现在两种布局共用同一棵组件树。

## 界面

- 构建记录列表在空间紧张时不再被挤变形：状态徽章可以收缩，提交和时间两列不再换行。

## Bukit

- **多文档 `site.yaml` 的提示更准确**：Bukit 2.2.6 只接受一个文档，不是忽略后面的内容。`bukit new` 也不再写出文档结束标记，新建网站不用再改文件。

## 已知问题

- macOS 安装包没有用开发者证书签名：第一次打开要右键点应用、选"打开"；每装一个新版本，macOS 会再问一次钥匙串，点"始终允许"即可。
- 应用内更新下载的安装包和校验文件来自同一个 GitHub 发布，没有独立签名，只适合测试使用。对外发布前会先决定签名方案。
- Intel Mac 和 Linux ARM 的安装包只经过发布流程里的冒烟测试，没有在真机上完整试用。
- Windows 版只是预览，还不支持。
