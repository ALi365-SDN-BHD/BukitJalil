# BukitJalil v0.1.0-beta.5

**每一次笔记，都值得被看见；让 AI 帮你实现它。**

这是测试版，适合自己试用，不建议用在正式网站上。和 beta.4 相比的主要变化如下。

## 新功能

- **上传图片和文件**：在网站页面把图片或 PDF 拖进来（或点选），文件放进当前主题的 `static/uploads/`，和其他改动一样先审核再应用；AI 能看到已上传的文件并在页面里引用。
- **发布前检查上传网址**：改了 `site.baseUrl` 后，正文里写死的旧上传网址会失效。构建报告会列出这些页面和网址；发布时有这类问题就停下，不会发出坏链接。
- **应用内更新**：左下角版本号后面有"更新"按钮，检查 GitHub 上的新版本，点"下载安装包"后在后台下载并校验，完成后打开安装程序（macOS dmg、Linux AppImage 或 deb）。从这个版本开始才有，beta.4 升级到本版仍需手动下载。
- **新平台**：第一次提供 Intel Mac（`mac-x64`）和 Linux ARM（`linux-arm64`）的安装包。

## 新建网站

- **改由内置 Bukit 的 `bukit new` 生成**，起步主题随 Bukit 更新：新版式、跟随系统的深色模式、窄屏折叠菜单；选简体中文时，界面文字（菜单、分页、搜索等）是中文。
- 已有网站的主题保存在网站目录里，升级后不会变；只有新建的网站用新主题。

## Bukit

- **内置 Bukit 升到 2.2.5**，AI 用的 Bukit 技能同步到 2.2.5。多语言技能补充了界面文字的写法：默认语言写在 `theme.params.labels`，其他语言写在 `data/<语言>/ui.yaml`。
- `site.yaml` 里 `...` 或 `---` 之后的内容会被 Bukit 静默忽略。现在构建前会拦下这种文件，并说明把设置移到这一行之前。

## 版本历史

- 应用改动时，提交说明第一行保留你自己写的说明（例如"恢复到某版本"），下面补注 AI 改过的文件。
- AI 参与过的改动集，即使对话已删除，作者仍记为 AI；整体应用和部分应用的规则一致。

## 已知问题

- macOS 安装包没有用开发者证书签名：第一次打开要右键点应用、选"打开"；每装一个新版本，macOS 会再问一次钥匙串，点"始终允许"即可。
- 应用内更新下载的安装包和校验文件来自同一个 GitHub 发布，没有独立签名，只适合测试使用。
- Intel Mac 和 Linux ARM 的安装包是第一次发布，只经过发布流程里的冒烟测试。
- 预览里的搜索页搜不出结果（预览禁止页面请求文件）；发布后的网站正常。
- Windows 版只是预览，还不支持。
