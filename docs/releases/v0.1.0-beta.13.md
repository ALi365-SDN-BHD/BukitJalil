# BukitJalil v0.1.0-beta.13

**每一次笔记，都值得被看见；让 AI 帮你实现它。**

这是测试版，适合自己试用，不建议用在正式网站上。和 beta.12 相比的主要变化如下。

## Bukit

- **内置 Bukit 仍是 2.2.9**，版本没有变。
- **AI 使用的 Bukit 技能说明同步到 2.2.9**（beta.12 时还是 2.2.7）。2.2.8 和 2.2.9 的新功能（数据索引里的对象值、命名查询、派生字段、按字段生成的永久链接、内容链接和反向链接等）现在 AI 也知道怎么写；BukitJalil 只接 Notion 数据源，AI 不会去写 CloudBase 内容源。

## 已知问题

- macOS 安装包没有用开发者证书签名：第一次打开要右键点应用、选"打开"。
- 应用内更新下载的安装包和校验文件来自同一个 GitHub 发布，没有独立签名，只适合测试使用。对外发布前会先决定签名方案。
- Intel Mac 和 Linux ARM 的安装包只经过发布流程里的冒烟测试，没有在真机上完整试用。
- Windows 版只是预览，还不支持。
