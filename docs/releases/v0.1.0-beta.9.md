# BukitJalil v0.1.0-beta.9

**每一次笔记，都值得被看见；让 AI 帮你实现它。**

这是测试版，适合自己试用，不建议用在正式网站上。和 beta.8 相比的主要变化如下。

## 导入网站

- **配置文件可以不叫 `site.yaml`**：导入时按文件内容找网站配置（根目录的 YAML 文件，顶层有 `site` 和 `theme`），不看文件名，也不会改名或改动你的文件。有多个候选时由你选一个。之后的构建、检查、预览、发布和 AI 修改都用这个文件。

## Windows

- Windows 版本继续做移植，测试已能在 Windows 上通过，但仍是预览，还没有在真机上完整验证。

## 已知问题

- macOS 安装包没有用开发者证书签名：第一次打开要右键点应用、选"打开"；每装一个新版本，macOS 会再问一次钥匙串，点"始终允许"即可。
- 应用内更新下载的安装包和校验文件来自同一个 GitHub 发布，没有独立签名，只适合测试使用。对外发布前会先决定签名方案。
- Intel Mac 和 Linux ARM 的安装包只经过发布流程里的冒烟测试，没有在真机上完整试用。
- Windows 版只是预览，还不支持。
